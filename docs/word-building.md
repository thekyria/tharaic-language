# Word Building

[← Overview](../README.md)

Tharaic builds new words in two layers, matching its two ancestral streams:

- an **older Phoenician-style layer**: vowel patterns and a few affixes applied to a consonantal root. It is mostly closed: speakers recognize the patterns but rarely coin new words with them.
- a **younger Greek-style layer**: suffixes added to an existing word. It is productive, and new words are made this way today.

---

- **μα-CaC-αρ** is modelled on the Phoenician *maqtal* place nouns.
- **θαρια** was built on *θᾱρος* after τ had become θ (change 1), so it keeps the θ but takes the collective's short vowel.
- **-υτον** is the one older suffix that still makes new words, because it can attach to any noun.

## Younger layer: suffixes

| Suffix | Gender, stem | Meaning | Base | Tharaic | Romanized | English |
|--------|--------------|---------|------|---------|-----------|---------|
| -ικος / -ικον | adjective | "of, relating to" | *ναϝᾱ* ship | *ναϝικος* | navikos | nautical |
| | | | *λακον* word | *λακικος* | lakikos | verbal, spoken |
| | | | *θᾱρος* sea | *θᾱρικος* | thārikos | maritime |
| -ιον | IN, ON-stem | diminutive | *ναϝᾱ* ship | *ναϝιον* | navion | little boat |
| | | | *παιδᾱ* child | *παιδιον* | paidion | little child |
| | | | *λιμᾱ* harbor | *λιμιον* | limion | cove, small harbor |
| -ευς | AN, see below | tradesman, one who works with X | *κασαφον* silver | *κασαφευς* | kasapheus | silversmith |
| | | | *ζαͱαρον* gold | *ζαͱαρευς* | zahareus | goldsmith |
| | | | *ͱαβλον* rope | *ͱαβλευς* | hableus | ropemaker |

**Diminutives are always inanimate**, even when the base noun is animate: *ναϝιον* "little boat" is IN although *ναϝᾱ* "ship" is AN. Greek *-ιον* neuters behave the same way. A little boat is a thing, not a living vessel.

### Nouns in -ευς

These decline like O-stems on a stem ending in **-εϝ-**. The nominative *-ευς* and vocative *-ευ* are the only special forms, from older \*-εϝος and \*-εϝε (compare the early Greek genitive \*βασιλῆϝος, Homeric βασιλῆος):

| Case | Singular |
|------|----------|
| **NOM** | *κασαφευς*<br>kasapheus |
| **ACC** | *κασαφεϝον*<br>kasaphevon |
| **GEN** | *κασαφεϝι*<br>kasaphevi |
| **DAT** | *κασαφεϝοι*<br>kasaphevoi |
| **VOC** | *κασαφευ*<br>kasapheu |
| **LOC** | *κασαφεϝελι*<br>kasapheveli |
| **INS** | *κασαφεϝομ*<br>kasaphevom |
| **ABL** | *κασαφεϝαθα*<br>kasaphevatha |

Dual and plural follow the O-stem on *κασαφεϝ-*: *κασαφεϝιν*, *κασαφεϝιμ*…
